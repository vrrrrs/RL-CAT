## 1. 项目是什么

**RL-CAT 是一只 12 自由度四足机器人**，目标是走通"机械设计 → 仿真 → 强化学习训练 → sim-to-real 部署"的完整链路。

| 项 | 值 |
|---|---|
| **自由度** | 12（每腿 3：髋外摆 + 髋俯仰 + 膝） |
| **整机质量** | 1.386 kg（CAD 实测） |
| **机身尺寸** | 200 × 72 × 58 mm |
| **站立高度** | 约 133 mm（仿真实测） |
| **执行器** | 12 × Feetech ST-3215-C018（12V 版）总线舵机 |
| **上位机** | 树莓派 5 (4GB) —— 跑 RL 策略 |
| **下位机** | STM32F103C8T6 —— 100 Hz 实时控制 |
| **控制频率** | 100 Hz |
| **观测 / 动作** | 47 维 / 12 维 |

### 1.1 设计优先级

```
功能  >  小巧美观
（机械必须小、好看，但功能优先）
```

## 2. 系统架构

```
┌─────────────────────────────────────────────────────────────┐
│  树莓派 5 (4GB)                                              │
│  · 运行 RL 策略（PyTorch / ONNX）                            │
│  · 100 Hz 推理 → 输出 12 维关节目标角                        │
└────────────────────┬────────────────────────────────────────┘
                     │ UART 500 kbps（自定义帧协议，交叉接线）
                     │ 下行：CMD_JOINT   上行：TEL_FAST (47 维观测)
┌────────────────────┴────────────────────────────────────────┐
│  STM32F103C8T6                                               │
│  · 100 Hz 控制环                                             │
│  · 舵机总线时序（SyncWrite / SyncRead）                       │
│  · 传感器采集（IMU 姿态、电池电压）                            │
│  · 安全保护（低压 / 超温 / 失联 → 趴下）                       │
└───────┬──────────────────────────┬──────────────────────────┘
        │ UART 500 kbps            │ 软件 I2C
        │ 直连（RX→RX, TX→TX）      │
┌───────┴──────────┐        ┌──────┴────────┐
│ 舵机控制板        │        │  JY901P IMU   │
│ (Waveshare A)    │        │ （内部融合）   │
│ 跳线 A 位         │        └───────────────┘
└───────┬──────────┘
        │ 半双工总线
┌───────┴──────────────────────────────────────┐
│  12 × ST-3215-C018 总线舵机                   │
│  供电：3S 电池经 16 AWG 粗线直供（绕过控制板）  │
└──────────────────────────────────────────────┘
```

## 4. 技术路线

```
机械设计（SolidWorks）
   ↓  导出 URDF（SW2URDF）
URDF + 质量属性修正
   ↓  构建仿真环境（Isaac Gym + legged_gym）
RL 训练（PPO）
   ↓  域随机化
策略导出（ONNX）
   ↓
真机部署：Pi 跑策略 → STM32 控舵机
   ↓  系统辨识 → 反哺仿真 → 重训（迭代）
sim-to-real 完成
```

### 4.2 ⚠️ 当前卡在哪

| 1 | ⚠️ **IMU 读不到** —— `safety_reasons = 0x40`（`RLCA_SAFE_R_IMU_STALE`）。寄存器配置与字节序均已核实正确，怀疑 `imu_poll()` 的陀螺离群值保护在反复丢帧。**它挡住 ACTIVE 准入门第 ④ 条。** |

| 4 | **舵机侧软限位** —— 上位机设 `Min/Max Angle Limit`（留 10~15% 余量，**勿动 `OFS`**）。这是独立于固件的最后一道保险 |

## 5. 已取得的成果（仿真）

**在 Isaac Gym 上从零搭起训练环境，训出可稳定行走的策略。**

| 验收项 | 结果 |
|---|---|
| 步态结构 | ✅ 标准对角小跑（非蹦跳/跛行） |
| 左右对称 | ✅ 占空比差 0.08~0.14 |
| **速度跟踪误差** | ✅ **0.060 ~ 0.099 m/s**（−0.3 ~ +0.5 m/s 全段，含后退） |
| 稳定性 | ✅ 32 环境 × 15 s **零摔倒** |
| 机身高度 | ✅ 0.105~0.120 m（目标 0.13） |

**训练规模**：2048 并行环境，12–19 万 steps/s，1000 迭代约 6–8 分钟（RTX 4060 Laptop）。

**完整报告**：[`Sim/RL/RL-CAT-训练实施报告.md`](../Sim/RL/RL-CAT-训练实施报告.md) —— 含 **9 轮调参的完整记录**，包括失败案例与根因分析。
