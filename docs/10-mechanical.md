## 1. 本文档的定位

**⚠️ 遵循一条原则：文档只写【不变量】，不写【会变的数值】。**

| 写 | 不写 |
|---|---|
| ✅ 设计意图、约束、坐标系约定、关节定义 | ❌ 具体尺寸（多少毫米） |
| ✅ "为什么这样设计" | ❌ 会随迭代变化的参数 |

**具体参数**原指向 `hardware/mechanical/参数.xlsx`（单一数据源）。

> ⚠️ **该文件不随本次开源发布**（机械设计未开源，见 [`hardware/README.md`](../hardware/README.md)）。
> 目前仓库里可查的机械数据只有 [`hardware/mechanical/URDF/robot.urdf`](../hardware/mechanical/URDF/robot.urdf)
> —— 它包含关节轴、限位、连杆质量与惯量，足以支撑仿真与限位判断，但**不含外形尺寸**。

**理由：** 旧版文档把讨论阶段的临时尺寸写进了正文，导致模型更新后文档立刻失效。避免这个问题的唯一办法是——**文档不记录会变的东西**。

## 2. 设计约束（不变量）

| # | 约束 |
|---|---|
| 1 | **功能优先于小巧美观** —— 机械要小、要好看，但功能不能让路 |
| 2 | **12 自由度**，四足，每腿 3 关节（髋外摆 + 髋俯仰 + 膝） |
| 3 | **3D 打印结构 + 总线舵机**（不用 PWM 舵机，因为需要位置反馈） |
| 4 | 足端为**球形橡胶**（起缓冲与抓地作用） |
| 5 | 电池、Pi、PCB 集成在机身内 |

## 3. 坐标系与关节约定

### 3.1 机身坐标系

```
X = 向前
Y = 向左
Z = 向上
原点 = 机身中段中心的地面投影
```

### 3.2 关节命名

**⚠️ 命名有歧义，详见 [`99-glossary.md`](99-glossary.md) §0。**

| 统一用 | 中文 | 转轴（机身系） |
|---|---|---|
| `hip` | 髋外摆 | 沿 **X**（前后方向） |
| `thigh` | 髋俯仰 | 沿 **Y**（左右方向） |
| `calf` | 膝 | 沿 **Y**（左右方向） |

**腿编号**：`lf`（左前）、`lb`（左后）、`rf`（右前）、`rb`（右后）

**关节全名**：`{腿}_{关节}`，例：`lf_hip`、`rb_thigh`

### 3.3 关节零位

```
URDF 的 q = 0  ←→  机器人处于【弯腿站立姿态】
```

**✅ 已实测确认**（`Sim/RL/RL-CAT-训练实施报告.md` §4.3）。

**⚠️ 零位 = CAD 装配姿态。这是设计上的有意选择：**

- 站立姿态是机器人**自然稳定、可重复**的姿态 → 便于真机标定（无需特殊夹具）
- 避免把零位放在"腿完全伸直"位 —— 那是**运动学奇异点**

## 4. 设计理由（不变量）

**⚠️ 本节只写"为什么"，具体数值原在 `参数.xlsx`（不随本次发布）。**

| # | 设计决定 | 理由 |
|---|---|---|
| 1 | **小腿不装舵机** | 减少末端质量与惯量，降低大腿舵机负担 |
| 2 | **髋外摆范围不对称（只向外）** | 不需要向内摆；向外摆用于调整支撑多边形 |
| 3 | **膝关节活动范围有限** | 深蹲能力受限，但站立与行走够用（见 `10-firmware.md` §3 的限位） |
| 4 | **机身宽度由电池决定** | 3S 18650 电池组的尺寸是机身宽度的下界 |
| 5 | **足端用球而非平面** | 点接触，降低对地面平整度的要求 |
| 6 | **髋间距横向 > 纵向稳定性需求** | 见归档文档 `方案_v1.md` §1.9 的重心与稳定性分析 |

## 5. 与仿真/固件的接口

**机械侧需要向其他子系统提供的东西：**

| 输出 | 给谁 | 形式 |
|---|---|---|
| **CAD 模型** | 仿真 | → URDF（见 [`40-simulation.md`](40-simulation.md)） |
| **关节轴心距** | 仿真、固件 | → `robot.urdf`（`参数.xlsx` 未发布） |
| **关节限位** | 固件 | → [`30-firmware.md`](30-firmware.md) §3 |
| **质量属性** | 仿真 | → URDF 的 `<inertial>` |
| **足端球半径** | 仿真碰撞体 | 见 `Sim/RL/RL-CAT-训练实施报告.md` §3.1 |

## 6. CAD 文件位置

```
hardware/mechanical/
├── 装配体/
│   ├── CAT/                主装配
│   └── Backup/             ⚠️ SolidWorks 自动备份
├── 零件/                   零件 + 第三方模型
├── URDF/                   ⚠️ 与 Sim/RL/urdf/ 重复，待统一
├── 参数.xlsx               ⚠️ 不随本次开源发布
```

**⚠️ `零件/` 中含第三方 CAD 模型**（Waveshare 控制板、Raspberry Pi 5、Feetech ST3215），开源前需确认授权。
