# RL-CAT 机械设计规格（CAD 开工用）

> 配套文档：`方案.md`（完整方案）、`项目流程.md`（流程分工）
> 本文档只放**建模时手边要对照**的东西：尺寸、坐标、流程、检查点。
>
> 标注规则：✅ 可直接用 ／ ⚠️ 必须 CAD 验证 ／ 🔒 不可改（改了要重算上游）

## 0. 一句话说明这份文档怎么用

```
① 先看 §1 的"可直接用的尺寸"——这些是从运动学和规格书解出来的，不用再算
② 然后看 §2 的建模顺序——按这个顺序做，返工最少
③ 每完成一个阶段，对照 §3 的检查点自检
④ 遇到冲突，回到 §4 找替代方案，不要自己改尺寸（会破坏上游计算）
```

## 1. CAD 需要引用的尺寸

### 1.1 舵机（Feetech ST-3215-C018）— 来自规格书

| 项 | 数值 | 备注 |
|---|---|---|
| 机体尺寸 | **45.2 × 24.7 × 35 mm** | |
| **输出轴位置** | 位于 24.7 × 45.2 面的中心 | 轴心距该面两长边各 12.35 mm |
| **输出轴规格** | **25T / OD 5.9 mm** | 有花键，和舵盘配合 |
| 输出轴（含齿）突出 | 约 10.2 mm | 需向卖家索取 STEP 模型确认 |
| 安装孔 | **4 × M3** | 孔位需按官方图纸 |
| 出力轴螺丝 | **M3 × 6** | |
| 重量 | **55 ± 1 g** | |
| 接插件 | 5264-3P，线长 **15 cm** | ⚠️ 对 120 mm 腿长可能偏短，需买延长线 |
| 引脚定义 | **1=GND, 2=Vcc, 3=Signal/TTL** | |

**⚠️ 建模第一步：向卖家索取 ST-3215-C018 的 STEP 模型**（Waveshare Wiki 的 [ST3215 3D Module](https://files.waveshare.com/upload/5/59/ST3215-3D.zip) 可作起点，但要核对是不是同一款）。**不要凭尺寸手搓舵机模型**——轴的位置和花键差 1 mm，整个腿部装配就废了。

### 1.2 腿的几何 🔒

```
              ● 髋俯仰轴  (z = 105.6 mm)
             ╱ ╲
      大腿 60╱   ╲
           ╱     ╲
          ╱ 123.3°╲          ← 膝角
         ●─────────● 膝  (z = 52.8 mm, 前后偏 28.5 mm)
             小腿 60
                  ╲
                   ● 足  (z = 0, 在髋正下方)
```

| 项 | 数值 | 说明 |
|---|---|---|
| **大腿**（髋俯仰轴 → 膝轴） | **60.0 mm** | 轴心到轴心 |
| **小腿**（膝轴 → 足端） | **60.0 mm** | 轴心到足端 |
| **总腿长 L** | **120.0 mm** | 站立姿态直线距离 |
| **站立髋高 h** | **105.6 mm** | h/L = 0.88 |
| 站姿膝角 | **123.3°** | 落在 90~130° 力矩最优区 |
| 大腿与垂直夹角 | 28.4° | |
| 小腿与垂直夹角 | 28.4° | |
| 足相对髋水平偏移 | **0 mm** | 站立时足在髋正下方 |
| **膝力臂 b** | **28.5 mm** | 决定膝扭矩的几何量，⚠️ 不要让它在全行程内过大 |

**膝活动范围：建议 60° ~ 150°**
- 对应腿长 60 ~ 120 mm，站高 52.8 ~ 114 mm
- **下限 60° 决定蹲伏深度，上限 150° 决定落地缓冲行程**

**足端：球形橡胶足，半径 8~10 mm**（点接触，让仿真接触模型更简单）

### 1.3 髋关节 🔒（有 2 处可调）

```
【外摆轴】沿 X（前后方向）
    ↓ 垂直下沉 15.0 mm
【髋俯仰轴】沿 Y（左右方向）
```

| 项 | 数值 | 可调性 |
|---|---|---|
| 髋外摆轴 → 髋俯仰轴 | **16.6 mm** | ⚠️ **建议加大到 20~22 mm** |
| ├─ 水平外偏 | 9.8 mm | |
| └─ 垂直下沉 | 15.0 mm | |
| 髋俯仰轴的横向位置 | 距机身中线 **40 mm** | ⚠️ 可微调到 36~38 mm |

**为什么要加大外摆臂（16.6 → 20~22 mm）：**

| 收益 | 代价 |
|---|---|
| 横向髋距从 60.4 变成 74~78 mm，**静态侧向稳定裕度大幅改善** | 外摆舵机扭矩从 19 mN·m 涨到 28 mN·m |
| 外摆时腿平面离机身更远，干涉余量更大 | **——依然可以忽略（额定扭矩的 3%）** |

**结论：这个加大几乎是免费的，建议做。**

### 1.4 髋轴间距 🔒

| 项 | 数值 |
|---|---|
| **纵向髋距 Lh**（前轴到后轴） | **150 mm**（= 1.25 × 腿长） |
| **横向髋距 Wh**（外摆轴，左到右） | **60.4 mm** |
| 横向髋距（髋俯仰轴，左到右） | 80 mm |

### 1.8 舵机线缆走向 🔒（必须预留）

```
每条腿 3 个舵机的 5264-3P 线：
   外摆舵机（机身内）───→ 沿机身
   髋俯仰舵机（外摆臂末端）───→ 随外摆臂摆动
   膝舵机（大腿远端）───→ 沿大腿走

关键：外摆臂摆动时，髋俯仰舵机的线要有余量
      膝舵机线不要固定在膝关节受力位置
```

### 1.9 足底开关的结构预留（v1 不装）

| 位置 | 预留 |
|---|---|
| 脚垫 | **8 × 8 × 3 mm 空腔** |
| 小腿侧面 | 2 × 3 mm 走线槽 |
| 大腿侧面 | 2 × 3 mm 走线槽 |
| **膝、髋两处** | **各 ≥15 mm 的走线松弛环空间** |

⚠️ **松弛环是最容易忘的。** 线如果绷直着跨过关节，全行程弯折几次就断。

## 2. 建模顺序（按这个顺序做，返工最少）

```
① 单腿建模
     外摆舵机 + 外摆臂 + 髋俯仰舵机 + 大腿 + 膝舵机 + 小腿 + 足
     目的：确认 60/60 的两段长度能装配、轴心距准
     ↓
② 全行程干涉检查  ★关键检查点 1
     外摆扫 -25° ~ +25°，膝扫 60° ~ 150°，组合扫一遍
     目的：确认腿部各段之间、腿与腿之间不穿模
     ↓
③ 肩部结构（外摆舵机怎么挂到机身上）
     目的：确定"总宽"到底是多少
     ↓
④ 机身骨架
     先只做能固定 4 组舵机的框架，不做外壳
     ↓
⑤ 内部器件摆放  ★关键检查点 2
     按这个顺序往机身里塞：电池 → Pi 5 → PCB → 驱动板 → 无线/IMU
     目的：确认 230 × 80 × 58 到底够不够
     ↓
⑥ 重心核算  ★关键检查点 3
     所有零件的质心加权平均，重心投影要落在支撑多边形内
     ↓
⑦ 外壳 / 走线槽 / 线缆通道
     ↓
⑧ 拆件出图 + 打印
     ↓
⑨ 装配验证  ★关键检查点 4
     ↓
⑩ 🚩 样机 v1 冻结（此后不再改结构）
```

### 为什么要先做单腿、后做机身

> **腿的尺寸是上游（决定扭矩预算），机身的尺寸是下游（由器件和舵机排布决定）。**
> 如果先做机身，做到一半发现腿的干涉没解决，机身的肩部位置全要改。
>
> **腿 → 干涉 → 肩部 → 机身** 这个顺序，返工最少。

## 3. 四个关键检查点

### ★ 检查点 1：全行程干涉

| 检查什么 | 判据 |
|---|---|
| 外摆 ±25° 时，腿是否撞机身 | 任何角度下 **间隙 ≥3 mm** |
| 膝 60°~150° 时，小腿是否撞大腿 | 全行程无穿模 |
| 四条腿同时外摆时，相邻腿是否互撞 | 前后腿间距 150 mm，**留 ≥10 mm** |
| 足端在可达范围内是否有干涉 | 可达半径 60~120 mm |

**⚠️ 最容易漏的是"组合情况"**：外摆 + 膝同时到极限。**要扫二维组合，不能只单独扫每个关节。**

### ★ 检查点 2：内部器件摆放

| 检查什么 | 判据 |
|---|---|
| **电池放得进去吗** | 3S 21700 横排 66 × 74 × 22 mm |
| Pi 5 放得进去吗 | 85 × 56 × 17 mm（+散热） |
| PCB 放得进去吗 | 目标 ~85 × 70 mm，**宽 ≤75 mm** |
| 接插件操作空间 | 每个接插件都要能插拔，**手能伸进去** |
| **走线有通道吗** | 大电流线（14~16 AWG）、舵机线、信号线都要有路径 |

**⚠️ 这一关是最可能推翻 230 × 80 × 58 的地方。** 如果发现放不下，**先改电池布局**（横排 → 2+1），再改机身尺寸。

### ★ 检查点 3：重心

| 检查什么 | 判据 |
|---|---|
| 重心投影位置 | 落在支撑多边形（150 × 60.4 mm）内 |
| 重心高度 | 目标 ≈54 mm，**低于髋轴 105.6 mm** ✅ |
| 配平手段 | 电池位置可调（最重的可移动件） |

**建议**：在 CAD 里给电池留 3~5 mm 的位置调整余量，方便后期配平。

### ★ 检查点 4：装配验证

| 检查什么 | 判据 |
|---|---|
| 12 个关节能用手自由转动 | 无卡涩 |
| 螺丝刀能伸到每个螺丝 | 尤其舵机安装螺丝 |
| 舵机线能插拔 | 5264-3P 接头要能拔下来 |
| **跑 30 分钟后复紧螺丝** | 3D 打印件会蠕变 |

## 4. 遇到冲突时的替代方案

**不要自己改 🔒 的尺寸**（会破坏上游的扭矩/带宽计算）。按下面的顺序妥协：

| 冲突 | 优先改 | 不要改 |
|---|---|---|
| 机身太长（>250 mm） | ① 改电池布局 ② 舵机排布紧凑化 | ❌ 纵向髋距 150 mm |
| 机身太宽（>125 mm） | ① 外摆舵机嵌入侧壁 10 mm（可省 20 mm）② 外摆臂缩短 | ❌ 髋俯仰轴横向偏移（会影响干涉） |
| 机身太高（>66 mm） | ① Pi 竖装（省 12）② 电池 2+1（省 9）③ 用薄散热片 | ❌ 腿部几何 |
| 器件放不下 | ① 改电池布局 ② 减小 PCB | ❌ 电池容量（会影响续航和配重） |
| 膝扭矩不够（余量 <20%） | ① 加大站姿比 h/L ② 减重 | ❌ 腿长（会连锁改所有尺寸） |
| 重心偏高 | ① 电池下移 ② 重件下移 | ❌ 腿长 |
| 总重超 1.9 kg | ① 减外壳 ② 减紧固件 ③ 打印件减壁厚 | ❌ 舵机 |

**⚠️ 最不该动的两个量：**
1. **纵向髋距 150 mm** — 由腿长 120 × 1.25 推出，改了会影响稳定性
2. **腿长 120 mm** — 由膝扭矩余量 32% 反推，改了要把整条扭矩链重算

## 5. 材料与工艺

| 部件 | 建议材料 | 理由 |
|---|---|---|
| **腿部连杆**（大腿、小腿） | **PETG 或 尼龙（PA/PA-CF）** | 要承受反复冲击。**PLA 太脆，不建议** |
| **髋支架 / 肩部** | PETG 或 尼龙 | 受力件 |
| **机身骨架** | PETG | 强度够、好打印 |
| **外壳 / 装饰件** | PLA 或 PETG | 不受力 |
| **足端** | TPU（软）或 橡胶 | 要缓冲 |

### 结构设计要点

| # | 要点 | 为什么 |
|---|---|---|
| 1 | 关节处用**金属轴承**，不要让塑料直接做轴孔 | 塑料轴孔磨损快，背隙会迅速增大 |
| 2 | 承力件壁厚 **≥3 mm** | |
| 3 | 打印方向：**层间不要垂直于主要受力方向** | 3D 打印件层间强度最弱 |
| 4 | 舵机安装孔用**热熔铜螺母**，不要自攻螺丝 | 反复拆装会滑丝 |
| 5 | 螺丝用 M3，配弹垫或螺纹胶 | 振动会松 |

## 6. 建模时的五个工程提醒

| # | 提醒 | 说明 |
|---|---|---|
| **1** | **先把舵机 STEP 弄到手** | 手搓舵机模型是最常见的错误来源。轴的位置差 1 mm，整条腿废 |
| **2** | **左右腿用镜像，但要注意方向** | 你的 `Cat` 项目里踩过这个坑（`270 - 角度`）。**镜像后舵机的转动方向会反过来**，软件侧要对应 |
| **3** | **给舵机线留长度** | 5264-3P 原配 15 cm，对 120 mm 腿长**可能不够**。CAD 里模拟一下线的路径 |
| **4** | **膝盖处的线要有松弛环** | 见 §1.9。这是小型四足最常见的断线位置 |
| **5** | **不要一次做完美** | `项目流程.md` 原则 1：**机械要早冻结，外观优化推迟到最后**。第一版的目标是"能装配、能动"，不是"好看" |
