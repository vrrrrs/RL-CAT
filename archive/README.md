## ⚠️ 勘误（重要）

### 勘误 1：`*_thigh` 关节限位不是阻塞项

**`RL-CAT项目交接文档_v1.md` 中的错误结论：**

> §0 最容易踩的坑：「`*_thigh` 的 +30° 上限 < 站立所需的 +31.19°」→ 标为 🔴 阻塞
> §13 关键提醒：「`*_thigh` 限位 +30° < 站立所需 +31.19° → 站立姿态超出限位，必须先放宽」

**实际情况（已由仿真实测证伪）：**

```
文档混淆了两个不同的角：
  · 大腿连杆相对竖直方向的绝对夹角（几何量）
  · 关节相对 CAD 零位的转角（URDF 的 q）

实际上：q = 0 就是装配好的站立姿态，
        所以站立时 thigh 关节角 = 0，离 +30° 上限还有 30° 余量。
```

**实测证据：** 机器人以原始 URDF 在 Isaac Gym 中成功站立并行走（见 `Sim/RL/RL-CAT-训练实施报告.md` §3.1、§3.2）。

**正确结论：** `*_thigh` 上限放宽到 90° 是**为了给摆腿留空间**，不是为了修复"站立够不到"。

### 勘误 2：观测向量是 47 维，不是 50 维

**`RL-CAT项目交接文档_v1.md` §12 写的是 50 维**（含 3 个"保留/待定"维）。

**实际实现是 47 维**（"方案 C" = 50 维设计的前 47 维），见 `Sim/RL/RL-CAT-训练实施报告.md` §4.1。

**当前有效的 47 维布局：**

```
 0– 2   重力向量（IMU 姿态反算）        3
 3– 5   机身角速度（陀螺）              3
 6– 8   速度指令 (vx, vy, ωz)           3
 9–20   关节位置（相对 q_default）      12
21–32   关节速度                       12
33–44   上一帧动作                     12
45–46   步态相位 sin/cos               2
                                      ──
                                      47
```

**⚠️ 固件侧的观测拼接必须按 47 维实现。**

### 勘误 3：URDF 关节零位的性质

**`RL-CAT项目交接文档_v1.md` §6.3 写的是"推断 q=0 是站立姿态，必须实测验证"。**

**现已实测确认**（`Sim/RL/RL-CAT-训练实施报告.md` §4.3）：
`default_joint_angles` 全为 0，且机器人确实站立成功。
