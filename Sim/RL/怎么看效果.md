# 怎么看训练效果

> 全部命令都要**先激活环境**，否则会报 `ModuleNotFoundError`：
> ```bash
> source $RLCAT_ROOT/scripts/env.sh
> ```

---

## 方法 1（最推荐）：开 3D 实时窗口看它走

比看录好的视频好得多 —— 可以自己拖视角、看细节。

```bash
source $RLCAT_ROOT/scripts/env.sh
cd $RLCAT_ROOT
python scripts/12_play.py
```

**会弹出窗口，脚本自动轮换速度指令**，终端实时打印每一步的跟踪误差：

```
 正在演示模型: Oct06_03-32-41_ / model_500.pt
 鼠标拖动转视角，滚轮缩放，ESC 退出
  [前进 0.00 m/s    ] 指令 +0.00  实测 +0.06  误差 0.065  机身高度 0.119
  [前进 0.20 m/s    ] 指令 +0.20  实测 +0.19  误差 0.014  机身高度 0.116
  [前进 0.40 m/s    ] 指令 +0.40  实测 +0.40  误差 0.003  机身高度 0.124
  [前进 0.50 m/s    ] 指令 +0.50  实测 +0.42  误差 0.081  机身高度 0.120
  [后退 0.20 m/s    ] 指令 -0.20  实测 -0.20  误差 0.004  机身高度 0.105
  [原地左转 0.6 rad/s] ...
  [斜着走 (vx=0.2, vy=0.15)] ...
```

**窗口操作**：鼠标拖动 = 转视角，滚轮 = 缩放，`ESC` = 退出。

**常用参数**：

```bash
python scripts/12_play.py --num_envs 4              # 同时看 4 只
python scripts/12_play.py --speeds "0.0,0.3,0.5"    # 只演示这几个速度
python scripts/12_play.py --secs_per_cmd 6          # 每个速度看 6 秒
python scripts/12_play.py --load_run Oct06_02-58-05_ --checkpoint 500   # 看别的轮次
```

> 看别的轮次时可用这些 run 名（都在 `~/legged_gym/logs/rlcat_flat/` 下）：
> `Oct06_03-32-41_`（最终，全达标）、`Oct06_02-58-05_`（对称性好但欠响应）、
> `Oct06_02-36-37_`（早期跛行版）、`Oct06_02-01-36_`（稳定基线版）

## 方法 2：用系统播放器看录好的视频

本机默认播放器是 **Totem（GNOME 视频）**：

```bash
xdg-open $RLCAT_ROOT/videos/v+0.30.mp4
```

或者**用文件管理器打开这个目录，双击任意 mp4**：

```
$RLCAT_ROOT/videos/
```

| 文件 | 内容 |
|---|---|
| `v+0.50.mp4` | 前进 0.5 m/s（最快） |
| `v+0.30.mp4` | 前进 0.3 m/s |
| `v+0.00.mp4` | 零指令（原地站立） |
| `v-0.20.mp4` | 后退 0.2 m/s |

> 视频是标准 H.264 / yuv420p / 1600×900 / 25fps，任何播放器都能开。
> **如果你的编辑器/预览器里点不开，那不是文件坏了，是它不支持视频播放** —— 用上面的播放器或方法 1。

## 方法 4：复现验收数据（跑一遍评估）

这是报告第 7 节那些数字的来源：

```bash
source $RLCAT_ROOT/scripts/env.sh
cd $RLCAT_ROOT
python scripts/07_eval.py --task rlcat --num_envs 32 --seconds 15 \
    --speeds="-0.3,-0.2,0.0,0.2,0.3,0.5" \
    --load_run Oct06_03-32-41_ --checkpoint 500
```

> ⚠️ `--speeds` 的值以 `-` 开头时**必须用 `=` 连接**（`--speeds="-0.3,..."`），
> 否则 argparse 会把它当成另一个选项，报 `expected one argument`。

## 方法 5：重新录视频（想换速度或换模型时）

```bash
source $RLCAT_ROOT/scripts/env.sh
cd $RLCAT_ROOT

# 抓帧（会开窗口，相机自动跟随机器人）
python scripts/07_eval.py --task rlcat --num_envs 4 --seconds 6 \
    --speeds="-0.2,0.0,0.3,0.5" --load_run Oct06_03-32-41_ --checkpoint 500 \
    --record --out eval_frames

# 合成 mp4 + gif + 合集
python scripts/09_frames_to_video.py --frames eval_frames --out videos --gif --combine
```

## 方法 6：看步态是否真的对称（不看画面，看数据）

```bash
source $RLCAT_ROOT/scripts/env.sh
cd $RLCAT_ROOT
python scripts/11_gait_analysis.py --task rlcat --checkpoint 500 --speeds "0.3"
```

会打印**足端接触时序的文本图**、各脚占空比、步频、关节使用情况：

```

主导步频 ≈ 6.00 Hz
```

## 如果想自己继续训练

```bash
source $RLCAT_ROOT/scripts/env.sh
cd $RLCAT_ROOT
bash scripts/run_train.sh rlcat --num_envs 2048 --max_iterations 1500    # 从头训
bash scripts/run_train.sh rlcat --resume --max_iterations 3000           # 续训
```

单轮 1500 迭代约 **8 分钟**（RTX 4060 Laptop，2048 环境，12~19 万 steps/s）。
改动奖励或配置在 `~/legged_gym/legged_gym/envs/rlcat/rlcat_config.py`。

> ⚠️ 训练时务必带 `--headless`（`run_train.sh` 已默认加上），否则渲染会拖慢一倍。
